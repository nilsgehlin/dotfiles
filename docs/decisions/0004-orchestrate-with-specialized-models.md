# Orchestrate with specialized models

Use GPT-5.6 Sol as the default, read-only primary orchestrator and reviewer, with GPT-5.6 Luna for small system tasks and subagents that perform repository exploration, implementation, and explicitly requested Git publication. Restrict the orchestrator to those named subagents, prevent nested delegation, and bound subagent steps so routine tool calls and implementation loops use the substantially cheaper model while architecture decisions and final review retain the stronger model. Limit the orchestrator and implementer to read-only Git inspection, and isolate staging, committing, and pushing in a Git-only agent so implementation never implicitly publishes work; add another implementation tier only if observed Luna failures justify the extra routing complexity.
